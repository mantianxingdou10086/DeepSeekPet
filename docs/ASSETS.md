# 素材来源与分发说明

本项目角色图片使用 Gemini 辅助生成，并在本地完成透明背景处理、分层、姿态整理与动画帧编辑。生成过程的聊天界面、原始生成记录、桌面截图和候选图片均不入库。

运行所需素材：

| 目录 | PNG 数量 | 用途 |
| --- | ---: | --- |
| assets/layered | 64 | 待机 |
| assets/happy | 64 | 开心和喂食 |
| assets/wakeup | 17 | 起床过渡 |
| assets/prone | 24 | 趴睡 |
| assets/typing | 3 | 专注敲键盘 |
| assets/rice | 3 | 吃白饭 |
| **合计** | **175** | 400×420 RGBA 动作帧 |

另含程序/托盘使用的 `pet.ico`。README 直接引用运行素材作为无隐私静态预览，没有额外上传运行窗口截图。
