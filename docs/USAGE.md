# 使用说明

完整解压 Release ZIP，双击 `DeepSeekPet.exe`，保留 `_internal`。所有角色交互均离线完成，不需要账户或 API Key。

- 左键拖动移动；单击摸头或叫醒；右键打开菜单；ESC 可退出。
- 专注可选 5/25/45 分钟。暂停动画不会暂停倒计时，也不暂停气泡显示时长。
- 隐藏到托盘不等于暂停。隐藏时不弹普通对白；专注结束后，恢复显示时补一条提醒，不反复补发。
- 托盘“显示桌宠”可找回窗口；“喂 Token”会明确显示桌宠并喂食。
- 大中小三档尺寸；空闲五分钟自动打盹可开关。
- 拖动、缩放和恢复显示时会检查显示器工作区，尽量避免角色落到任务栏或屏外。多屏和缩放行为仍可能因系统配置不同而异。
- 重复启动不会新开第二只。如果看不到，请先找任务栏通知区域（含折叠图标）中的托盘图标。

偏好保存在 `%LOCALAPPDATA%\DeepSeekPet\settings.json`，日志为同目录 `desktop.log`（滚动限额）。不保存专注进度或延期提醒；退出即结束本次计时。需要恢复默认时，先退出，再备份并移走 settings.json。

更新前退出旧程序，完整替换程序目录。下载的便携版本无需安装 Python，源码运行则需要依赖。未签名程序可能触发 SmartScreen，请只运行可信来源的文件并校验 SHA256。
